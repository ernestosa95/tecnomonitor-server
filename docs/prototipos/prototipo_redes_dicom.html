Qué está simulado en este prototipo
  • El layout de la pestaña 1 y las tarjetas de reglas de la pestaña 2 reproducen el dashboard y la pestaña Software actuales de index_beta.html; lo nuevo está marcado o resaltado.
  • El mapa es un SVG con las provincias del provincias_argentina.geojson del repo (para funcionar sin internet); en la implementación real sería Leaflet con los mismos controles y marcadores.
  • La clasificación de reglas (en red / propia / otra red / externa), las sugerencias, las advertencias y el color de cada enlace se calculan de verdad a partir de los datos de ejemplo: si asignás un destino en la pestaña 4, cambian las pestañas 1 y 2.
  • Los colores de las tres redes (azul, violeta, magenta) pasaron el validador de paleta categórica (separación para daltonismo y contraste), y la red nunca depende solo del color: hay etiqueta, y el rol se distingue por forma.
